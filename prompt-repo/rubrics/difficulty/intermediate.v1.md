# Intermediate Difficulty Rubric

**Cognitive level:** Bloom's `understand`, `apply`, light `analyze`.

**Acceptable item shapes**
- Apply a single concept to a slightly novel scenario.
- Two-step calculation requiring one unit conversion OR one formula substitution.
- "Given X and Y, find Z" where Z requires picking the right formula then computing.
- Compare two related quantities (e.g. which has higher boiling-point elevation).

**Reject if**
- Pure recall (move to Easy).
- More than two reasoning steps (move to Hard).
- Requires graphical/diagram interpretation unless the item is explicitly visual.

**Distractors**
- Target the most common student misconception explicitly.
- Include the result of using the wrong formula.
- Include the right answer with the wrong unit.
